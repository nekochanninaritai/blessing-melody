# 企画書

## プロジェクト名

蝶が運ぶ、はじまりの旋律

リポジトリ名は、READMEの公開URLから `blessing-melody` と確認できる。

## プロジェクト概要

結婚式のゲスト向けに制作された、物語仕立ての謎解きWebサイト。ゲストは「祝福の館」を舞台に、蝶に導かれながら四つの謎を解き、オルゴールへ四つの旋律を戻していく。

実装は `index.html`、`style.css`、`script.js` を中心とした静的Webサイトであり、React、Vite、ビルドツールの使用はコード上では確認できない。

## 制作背景

READMEおよび画面内テキストから、結婚式当日にゲストがスマートフォンで楽しむ演出コンテンツとして制作されていることが確認できる。

新郎新婦や式場の具体的背景、制作経緯の詳細はコード上では確認できない。

## 制作目的

- 結婚式ゲストに待ち時間や歓談中に楽しめる体験を提供する
- 謎解きを通じて、ゲストが新郎新婦への祝福を完成させる体験を作る
- エピローグ、署名、抽選、Extra Contentsにより、ゲーム後の余韻と参加感を残す

## コンセプト

「蝶に導かれ、祝福の館に眠るオルゴールへ四つの旋律を戻す物語」。

アンティークな洋館、蝶、オルゴール、音楽、手紙、祝福をモチーフとし、ホラーではなく温かく上品なファンタジーとして構成されている。

## 想定ユーザー

- 結婚式に参列するゲスト
- スマートフォンでアクセスするユーザー
- 謎解きや物語演出を短時間で楽しむユーザー

管理者・運営者向けの専用画面はコード上では確認できない。

## 利用シーン

- 結婚式当日の待ち時間
- 披露宴会場での参加型演出
- エンディング到達者向けの署名、抽選、Extra Contents閲覧

## 提供価値

- ゲストが「祝福を届ける」役割を持てる
- 謎解き、音楽、ビジュアル演出により式の世界観を補強する
- Firebase Realtime Databaseにより署名と抽選参加を共有・保存できる
- GitHub Pagesで公開しやすい静的構成

## 主な機能

- 表紙画面
- ストーリー画面
- 4問の謎解き画面
- 正解判定と復元ページ
- エピローグ
- 祝福の署名
- プレゼント抽選参加
- Extra Contents
- CREDITオーバーレイ
- BGM、効果音、音ON/OFF
- localStorageによる進行状況保存
- Firebase Realtime Databaseによる署名・抽選データ保存

## ユーザー体験の流れ

1. 表紙から「祝福の館へ入る」
2. Preludeを読む
3. 各章のストーリーを読む
4. 謎を解く
5. 正解すると旋律が戻る
6. 4問を解くとエピローグへ進む
7. 祝福の署名、抽選参加を行う
8. Extra Contents、CREDITを閲覧できる

## 世界観・デザイン方針

コードとCSSから以下が確認できる。

- アンティーク、洋館、紙、楽譜、蝶、オルゴールをモチーフ化
- アイボリー、セピア、ブラウン、ゴールド系の配色
- 紙面風カード、装飾フレーム、光、蝶、音符、歯車の演出

## 制約事項・注意事項

- ブラウザの音声自動再生制限により、ユーザー操作後に音声を開始する実装
- Firebase設定がない場合はローカル保存にフォールバック
- 署名・抽選データは公開DBに送信されるため、入力値やルール管理に注意が必要
- `package.json` が存在しないため、npmによるビルド・テストは現状では実行対象外
