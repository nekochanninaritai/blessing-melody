## 環境変数の設定方法

環境変数参照はコード上では確認できない。Firebase接続先は `firebaseConfig.js` に定義される。

## Firebase設定時の注意

`firebaseConfig.js`:

```js
window.WEDDING_FIREBASE_CONFIG = {
  databaseURL: "https://YOUR_PROJECT_ID-default-rtdb.firebaseio.com"
};
```

実URLや認証情報をドキュメントへ転記しない。Firebase Realtime Databaseのルール実体はリポジトリ内では確認できないため、Firebase Consoleで確認する。

## コンテンツ変更方法

主な文章、問題、回答は `script.js` 先頭の `pages` 配列で管理される。

- `title`: 画面タイトル
- `text`: ストーリー本文
- `question`: 問題文
- `questionImage`: 問題画像パス
- `answer`: 正解
- `explanation`: 正解後説明
- `restoredText`: 旋律表示名

## 画像差し替え方法

画像は `assets/images/` に配置する。既存ファイル名を差し替えるとコード変更なしで反映しやすい。

主な画像:

- `question1.jpg` から `question4.jpg`
- `letter.jpg`
- `ending_letter.jpg`
- `story-ending.jpg`
- `title_butterfly.png`
- `butterfly.gif`

画像差し替え後は、ブラウザキャッシュ対策として `index.html`、`style.css`、`script.js` 内のクエリ文字列更新が必要な場合がある。

## 音声差し替え方法

音声は `assets/audio/` に配置され、`script.js` の `audioPaths` で参照される。

- `プロローグ.mp3`
- `1章.mp3`
- `2章.mp3`
- `3章.mp3`
- `4章.mp3`
- `エンディング.mp3`
- `click.mp3`
- `correct.mp3`
- `wrong.mp3`

バックアップ音源 `assets/audio/bk/` は `.gitignore` 対象。

## 問題文・正解変更方法

`script.js` の `pages` 配列内で対象問題の `question`、`questionImage`、`answer`、`explanation` を変更する。

正解判定は正規化されるため、全角カタカナ表記で登録しておくと管理しやすい。

## データ確認方法

- Firebase Consoleで `/butterflyMiracleRecords` と `/lotteryEntries` を確認
- ブラウザ開発者ツールのApplicationタブでlocalStorageを確認
- NetworkタブでFirebase REST APIへの通信を確認

## 障害時の確認箇所

| 事象 | 確認箇所 |
| --- | --- |
| 画像が出ない | パス、ファイル名、大文字小文字、キャッシュ |
| 音が出ない | 音ON操作、ブラウザ制限、音源パス |
| 署名できない | `firebaseConfig.js`、Firebaseルール、Networkエラー |
| 抽選できない | `/lotteryEntries` 書き込み権限、localStorage |
| 進行が戻る | localStorage削除、ブラウザ設定 |
| GitHub Pagesで古い表示 | `index.html` のCSS/JSクエリ、ブラウザキャッシュ |

## よくあるエラー

- Firebase URL先頭に余分な文字が入ると保存に失敗する
- `assets/images/question1.png` ではなく、現在の問題1は `question1.jpg` を参照している
- GitHub Pagesは大文字小文字を区別するため、ローカルで見えても公開後に表示されない場合がある
- `npm.cmd run build` は現状 `package.json` がないため実行できない
