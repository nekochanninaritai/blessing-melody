## 入力値とバリデーション

| 入力 | バリデーション |
| --- | --- |
| 謎解き回答 | 前後空白吸収、ひらがな/カタカナ、全角/半角を正規化 |
| 署名ニックネーム | 空欄不可、前後空白削除、最大20文字 |
| 抽選 | 同一端末ではlocalStorageにより1回のみ |

HTMLタグやスクリプト対策として、表示時に `escapeHtml` が使用される。

## 画面表示条件

- `currentPageIndex` が `unlockedPageIndex` を超える場合は封印ページを表示
- `page.type` に応じて描画関数を切り替え
- 抽選参加済みの場合は「抽選受付済み」ボタンを表示
- 署名一覧が空の場合は「まだ署名はありません。」を表示

## ステップ・進行状態の管理方法

進行状態は `state` オブジェクトで管理され、ページ移動、解放、回答入力、正解時に `saveProgress` で保存される。

## FirebaseまたはAPIとの通信処理

Firebase Realtime Database REST APIを `fetch` で呼び出す。SDKは使用されていない。

- `GET /butterflyMiracleRecords.json`
- `POST /butterflyMiracleRecords.json`
- `GET /lotteryEntries.json`
- `PUT /lotteryEntries/number-{number}.json`
- `POST /lotteryEntries.json`
- `PATCH /lotteryEntries/{firebaseKey}.json`

## 非同期処理

- Firebaseの取得・保存
- 音声再生 `audio.play()`

## エラーハンドリング

Firebase保存・取得失敗時は画面上に日本語メッセージを表示する。音声再生失敗はブラウザ制限を考慮し、例外を画面には出さない。

## 音声再生・停止処理

- ユーザー操作後に音声ON
- BGMはページ種別や復元済み章に応じて切替
- 効果音はクリック、正解、不正解で再生
- `visibilitychange`、`pagehide`、`beforeunload`、`blur` で停止
- 戻っても自動再生を強制しない

## アニメーション処理

CSSアニメーションで蝶、光、紙面、ボタン、CREDITなどを演出。`prefers-reduced-motion` で軽減するCSSが存在する。

## レスポンシブ制御

CSSメディアクエリとJSの `updatePageOverflow` により、画面内に収まる場合は不要なスクロールを抑制し、超える場合のみスクロール可能にする。
